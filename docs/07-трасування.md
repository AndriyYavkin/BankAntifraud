# 7. Трасування вимог (лекція 11)

Таблиці показують, що кожна потреба користувача реалізована функцією системи та перевірена тестом.

## Потреби користувачів

| № | Потреба | Хто |
|---|---|---|
| П-1 | Швидко і надійно переказати кошти | Операціоніст |
| П-2 | Знати точну причину відмови | Операціоніст |
| П-3 | Гроші не зникають і не з'являються | Клієнт, банк |
| П-4 | Виявляти й зупиняти шахрайські операції | Аналітик |
| П-5 | Розслідувати конкретну операцію | Аналітик |
| П-6 | Бачити стан бази даних і транзакцій | Адміністратор |
| П-7 | Дізнаватись про проблеми автоматично | Адміністратор, аналітик |
| П-8 | Допускати лише своїх працівників і лише до потрібних дій | Банк |
| П-9 | Перекази не зупиняються через збій аналізу | Операціоніст |
